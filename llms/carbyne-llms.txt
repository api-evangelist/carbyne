# Carbyne

> Cloud-native mission-critical contact center and emergency communications platform for 9-1-1, 3-1-1 and non-emergency call handling. Sold as Axon 911 Core and Carbyne APEX to Public Safety Answering Points (PSAPs), transportation, education and enterprise security operations. Founded 2015 (as Reporty Homeland Security), New York and Tel Aviv; acquired by Axon Enterprise in 2025.

Generated by the API Evangelist enrichment pipeline on 2026-08-02 from https://carbyne.com/ and the artifacts in this repository. Carbyne serves no llms.txt of its own (https://carbyne.com/llms.txt returns 404).

## API status

Carbyne operates an API program governed by published API Terms of Use, and markets an "open API" for integration with CAD, ESInet, voice recorders, PBX, mapping, IoT and SSO systems. As of 2026-08-02 it publishes **no public machine-readable API contract and no public developer documentation**. API access is granted to contracted customers and partners.

- API Terms of Use (PDF): https://carbyne.com/wp-content/uploads/2023/03/Carbyne-API-Terms-of-Use.final_.3.23.23.pdf
- Integrations overview: https://carbyne.com/cloud-advantage/carbyne-integrations/
- Partners: https://carbyne.com/partners/

## Platform

- [Axon 911 Core, by Carbyne](https://carbyne.com/solutions/apex/): Cloud-native 911 call handling infrastructure.
- [Carbyne APEX](https://carbyne.com/solutions/apex/): Complete call management platform — live video, caller location, mapping, triage and translation.
- [Continuity](https://carbyne.com/solutions/apex/continuity/): Failover backup for uninterrupted 9-1-1 operations.
- [Emergency Call Triage](https://carbyne.com/solutions/emergency-call-triage/): AI-assisted call triage.
- [Transcription & Translation](https://carbyne.com/solutions/translation/): Real-time transcription and language translation.
- [Bridge Desk](https://carbyne.com/solutions/bridge-desk/): 360-visibility command surface integrating alarms, CCTV and mobile assets.
- [Responder Connect](https://carbyne.com/solutions/responder-connect/): On-the-move situational awareness for responders.
- [Control Center](https://carbyne.com/solutions/control-center/): Command and dispatch console.
- [Wallboards](https://carbyne.com/solutions/wallboards/): Real-time operational displays.
- [Analytics](https://carbyne.com/solutions/analytics/): Operational data and insights.
- [Events History](https://carbyne.com/solutions/events-history/): Incident record retention.
